🕵️ Caso 1 — A banana feia

Um mercado joga fora 30% das bananas porque estão "feias", mesmo boas para comer.

Onde está a CAUSA RAIZ?

  • A) O caminhão amassou as bananas
  • B) O mercado só compra e vende o que é "bonito" ✅
  • C) As pessoas não gostam de banana
A raiz não é a banana feia — é a regra de aparência do mercado. Mudando a regra, o desperdício cai.

🕵️ Caso 2 — A geladeira esquecida

Uma família compra comida para a semana e, na sexta, metade está estragada.

Onde está a CAUSA RAIZ?

  • A) A comida estraga rápido
  • B) A geladeira é pequena
  • C) Compram sem planejar o que vão comer ✅
Raiz = falta de planejamento. A solução não é comprar mais geladeira — é planejar antes de comprar.

🕵️ Caso 3 — O tamanho único

Um restaurante serve porção gigante; os clientes deixam metade no prato.

Onde está a CAUSA RAIZ?

  • A) Os clientes não têm educação
  • B) O modelo de porção não considera o apetite real ✅
  • C) A comida é ruim
Raiz = decisão de negócio, não o cliente. Quem resolve a causa muda o modelo, não culpa a pessoa.

💻 O código

Leia com a turma ANTES de rodar: cada linha tem um trabalho.

local part = script.Parent

local function onTouch(otherPart)
    local character = otherPart.Parent
    if character and character:FindFirstChild("Humanoid") then
        part:Destroy()
    end
end

part.Touched:Connect(onTouch)
LinhaO que faz
local part = script.ParentGuarda "o objeto onde estou dentro" na variável part
local function onTouch(otherPart)Cria a função que roda no toque; otherPart = quem tocou
local character = otherPart.ParentSobe um nível: de "a mão" para "o personagem"
if character and character:FindFirstChild("Humanoid")Só continua se quem tocou for um personagem
part:Destroy()Destrói o objeto — o desperdício some
part.Touched:Connect(onTouch)Liga o evento de toque à função (fica "ouvindo")

🧩 Nível 2 — o lixo foge

Junte o movimento da Aula 1 com o destroy de hoje. Faça junto, linha por linha.

local part = script.Parent
part.Anchored = true

local function onTouch(otherPart)
    local character = otherPart.Parent
    if character and character:FindFirstChild("Humanoid") then
        part:Destroy()
    end
end

part.Touched:Connect(onTouch)

task.spawn(function()
    while part.Parent do
        for i = 1, 40 do
            part.Position = part.Position + Vector3.new(0, 0.1, 0)
            task.wait(0.05)
        end
        for i = 1, 40 do
            part.Position = part.Position - Vector3.new(0, 0.1, 0)
            task.wait(0.05)
        end
    end
end)
TrechoO que faz
part.Anchored = trueTrava a parte para o script controlar o movimento
task.spawn(function() … end)Roda o movimento em paralelo, sem travar o jogo
while part.Parent doContinua enquanto o objeto existir (para sozinho ao destruir)
+ Vector3.new(0, 0.1, 0)Sobe 0,1 stud por passo (40 passos ≈ 4 studs em 2 s)
task.wait(0.05)Espera 0,05 s entre os passos
segundo for com -Desce a mesma distância: sobe e desce em loop
